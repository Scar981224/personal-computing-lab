# Personal Computing Lab Documentation

本目录用于保存项目的技术文档、
研发规范、实验记录和重要决策。

## Documentation Structure

### 00 Project Management
项目管理、进度与技术决策。

### 01 Computer Basics
计算机组成、操作系统与网络。

### 02 Software Development
Python、Git、软件工程与测试。

### 03 AI Engineering
模型、Agent、RAG 与 AI 部署。

### 04 Industrial Applications
工业数据、工程软件与工业 AI。

### 05 Technology Research
技术趋势、市场研究与商业分析。

## Documentation Principles

- 保留资料来源。
- 区分事实、推测与建议。
- 重要技术结论需要验证。
- 更新已有文档优先于重复创建。
- 使用 Git 记录文档变更。
