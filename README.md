# Personal Computing Lab

个人计算实验室：通过真实项目学习计算机系统、软件工程和人工智能，并探索技术服务与产品化的可能性。

## Project Goals

- 建立计算机系统与软件工程基础。
- 学习 Python、Git 和现代软件开发。
- 从 AI 应用逐步深入模型工程。
- 探索 AI 在制造业、工程软件和工业数据分析中的应用。
- 建立可复现、可公开展示的 GitHub 作品集。

## Research Directions

1. Computer Systems
2. Software Development
3. AI Engineering
4. Industrial Applications
5. Technology and Market Research

## Working Principles

- 以真实项目驱动学习。
- 重视底层原理和工程实践。
- 所有重要成果都需要测试和验证。
- 使用 AI 辅助研发，但保留独立判断能力。
- 持续记录技术决策和学习成果。
